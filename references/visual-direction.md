# 从一句旁白选一种可见的证明

| 旁白在做什么 | 版式及动作 | 观众能看到的证据 |
| --- | --- | --- |
| 比较、反转、权衡 | 放在同一尺度或同一个支点上。一个条件改变，结果从 A 倾向 B | 用同尺度的长短、数量或天平倾向体现比较关系，标签指出比较的对象与单位 |
| 找原因、做前后对照 | 锁定构图和样本，只改一项。保留原图一角或用分隔线逐步揭示 | 修改前后的差异集中在同一部位，观众能指出哪个条件影响了结果 |
| 测试机制或操作 | 并排放实际对象与状态，沿一次完整操作推进 | 收藏按钮无响应 → 找到绑定 → 再点 → 已收藏。按钮、状态及结果一一对应 |
| 多种尝试、选择、排除 | 固定目标与卡片位置。虚线画候选，实线画已试，给失败和重试各一个可见结果 | 看得出哪条路径试过、失败在哪里；筛选时保留位置，仅强调保留项、淡出暂缓项 |
| 排查和归因 | 将具体事件与测量并列，共用同一事件时钟 | 同一帧上角色停顿、游标进入长帧区、标记亮起。虚构数据明确标「示意」 |
| 从总论回到例子／概括 | 带回一个熟悉对象，给它新的任务、尺度或关系 | 开场体验现象，中段修改对象，结尾用观众已见过的差异解释选择。结尾另画路径也能呼应开头的天平 |

每章先画一张无字幕草图。长流程用宽幅，局部判断用一幅大图加近邻标签，简短问题可放左侧。优先打磨二维图形的轮廓、层级、留白和对齐。题材涉及空间关系且三维能揭示新信息时再采用三维。画面中写对象名、状态和单位；复杂论证交给原声。让不了解原稿的人关字幕回答「哪两个东西在比、变的是谁、发生了什么」。

**节拍。** 给焦点一个语音触发词，一个词驱动标签、高亮和下划线。三者可有不同缓动，但应在同一短时段里开始可见。文字先浅后深，线从短到长，旧重点退场。先给自然示例，标签等词到才出现。短时间骤现的标题，往往是进入条件太晚而下一镜已经开始；延长可读状态、移到合适下一句，或直接删掉这一层标题。旧镜和新镜分别按各自时间绘制，避免旧图借新时钟透出下一句。参数可从约 0.3 秒文字显现试起。

**转场。** 同一场景接下一属性，留住主体，改变它的状态。主体从概览进入工作台，按相同轮廓和方向衔接两个位置。论证对象改变，先让旧图退场，再引入新图，尤其避免两组汉字叠化成重影。测试进场前一帧、过渡中、结束后和拖动进度条后的结果。动作用剪后时钟的函数计算，暂停或跳转到同一帧应得到相同画面。

**排版。** 先给主体、图例、字幕各自分区。字宽按最终字体和字重测量；为描线、圆角、箭头尖端、高亮外圈和缩放后的视觉边界留空间。引线从主体外缘出发，在标签外缘前停笔，路线避开其他文字。标签旁边可放与目标配对的形状符号；多个连接线相互交叉时尤其有效。线段收起到零就停止绘制，避免端点越过原点形成残线。比较项移动会相互穿过时，改为固定槽位。

可借鉴的原始案例：[用同一对象连接多层表示](https://worrydream.com/LadderOfAbstraction/)、[固定场景中改变成像条件](https://ciechanow.ski/cameras-and-lenses/)、[把运动与图线上的点对应](https://www.3blue1brown.com/lessons/derivatives/)。借其解释方法，自行绘制与本次论点相关的素材。
