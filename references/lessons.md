# 把返工经验用到下一部片

以下经验来自旁白图解的制作与返工。数字和场景只是故障例子；诊断时以当前项目的时间线和构图为准。

| 观察到的问题 | 原因与可复用的处理 |
| --- | --- |
| 选题时要防标题承诺超过内容 | 将标题与开场例子、结尾结论、主张的适用条件放在一起读。让标题承诺能由全片兑现，按约定的审批节奏推进封面 |
| 抠掉外围黑色，头发与脸之间、腋下仍黑，边缘泛绿 | 分查孔洞、前景保护和去绿溢色。在实际底色验收。人物影响阅读时，可用无人物的整页图解并重排 |
| 字幕和人物抢画面；短视频没有可用封面 | 图例、旁白字幕和人物各有职责。横、竖封面从草图阶段分别安排，竖版重新排主题物和标题 |
| 删掉解释后，图上只剩一个概念名 | 文字精简也要保留对象名和关系。用天平转向或同尺度长短显示谁超过谁，图例标出两边对象。关字幕让别人复述 |
| 低精度三维没有信息，动画也看不出重点 | 对比、状态和关系通常能用精细二维画明白。用一次局部高亮或配对图标指明当下焦点 |
| 开头尚未介绍天空盒、模糊描述、具体要求，标签已经给出答案 | 先展示一幅能观察的场景。对象可在图中，术语等旁白说到再进入 |
| 一段长旁白只在几张旧图之间切换 | 给每句配一个可见问题；把网站、测试、流失和改法做成连续的小实验。先打磨解释，再用音乐增强节奏 |
| 为满足静态指标加入整页推拉，观看更累 | 删除整页运动，再查一次静态窗；用新的证据填补。例如用用户路径显示操作从四步缩到两步 |
| 局部改得不错，整片仍重复同一画面，结尾又放原天平 | 通览全片的镜头清单。允许同一主体回归，但改变它承担的问题。结尾从原因解释结果，再进入路线选择 |
| 远山和下划线先亮，标签迟约两秒，看起来像音画不同步 | 先查干声时差，再查局部的两套触发。标签、高亮和描线共用一个剪后词点，分别缓入并按编码帧复核 |
| 联动对象各跑各的，转场失去连续性 | 角色卡顿与帧耗时图共用同一事件；同一对象的跨镜位置做匹配，文字退场后再入场 |
| 图例压住图形、候选卡片互穿，「AI 辅助」旁边出现残线 | 给实际笔画和箭头留边距；候选固定槽位。闸门打开后结束绘线，检查长度归零后是否反向延长 |
| 新标签出现前短暂闪过异句 | 查普通字在整个镜头里的可读时间；检查旧画面取样时钟、标签门控和剪点。用编码成片逐帧看问题区域 |
| 原声口语正常，字幕却处处是括号 | 原稿用来核实意图，口语按实录。只给真正补语病、消除逻辑断裂的改词加括号 |
| 音乐显得阴郁，提示音像系统报错；换强鼓点后轻声字又被盖住 | 用实际旁白试听授权素材，保持鼓点和贝斯的律动，给轻声短语一条音量包络。错误／确认／翻页等连续提示音收为少数物理动作 |
| 给了局部样片、本地路径或源码包，远端看不到完整版本 | 样片用于决策，交付入口始终指向完整成片。验证发布状态、权限、链接、哈希和工程包内容后再报告完成 |
| 单机正常，长片导出或远程打包后偏移、缺件 | 防首 PTS 与 AAC 预留样本、检查完整解码，中断按段恢复。远端重建后校验成品而非仅比对分片，发布前核查当前项目的章节和交付约定 |
